# LaTeX 数学公式入门

## 这门课是什么

数学交流需要公式。聊天输入框不支持所见即所得公式编辑器，因此这门课教你两套表达：

1. **标准 LaTeX**：精确、通用，适合写给会渲染 LaTeX 的地方（本仓库的 Markdown、Overleaf、Jupyter）；
2. **纯文本简化记号**：适合在聊天里快速写给 AI——不要求你背 LaTeX，用 `^`、`_`、`mat(...)` 这类自然写法，AI 也能准确理解。

## 标准 LaTeX：最小可用集

本仓库约定（与渲染器一致）：

- 行内公式：`$a^2 + b^2 = c^2$` → $a^2 + b^2 = c^2$
- 块级公式：`$$...$$` 独占一段

| 要写 | 输入 | 渲染 |
|------|------|------|
| 分数 | `\frac{a}{b}` | $\frac{a}{b}$ |
| 上标 | `a^{n+1}` | $a^{n+1}$ |
| 下标 | `x_i` | $x_i$ |
| 根号 | `\sqrt{x}`、`\sqrt[3]{x}` | $\sqrt{x}$、$\sqrt[3]{x}$ |
| 希腊字母 | `\alpha \beta \pi \varphi` | $\alpha\ \beta\ \pi\ \varphi$ |
| 求和 | `\sum_{i=1}^{n} a_i` | $\sum_{i=1}^{n} a_i$ |
| 积分 | `\int_a^b f(x)\,dx` | $\int_a^b f(x)\,dx$ |
| 极限 | `\lim_{x \to 0}` | $\lim_{x \to 0}$ |
| 同余 | `a \equiv b \pmod m` | $a\equiv b\pmod m$ |
| 矩阵 | `\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}` | $\begin{pmatrix}1&2\\3&4\end{pmatrix}$ |
| 分段 | `\begin{cases} x & x>0 \\ -x & x\le0 \end{cases}` | |
| 集合 | `\{x \in \mathbb{R} : x^2<2\}` | $\{x\in\mathbb R:x^2<2\}$ |
| 量词 | `\forall`、`\exists` | $\forall$、$\exists$ |
| 箭头 | `\to`、`\Rightarrow`、`\iff` | $\to$、$\Rightarrow$、$\iff$ |
| 竖线 | `a \mid b`（整除）、`|x|` | $a\mid b$、$|x|$ |

**注意**：本仓库校验器只接受 `$...$` 与 `$$...$$`，不要用 `\(...\)`、`\[...\]`。

## 纯文本简化记号（写给 AI 聊天）

你不需要背 LaTeX。聊天时用这些自然写法，AI 都能读懂——**关键是避免歧义**，写清边界：

| 数学对象 | 简化写法 | 备注 |
|----------|----------|------|
| 上标 | `a^2`、`a^(n+1)` | 复杂指数加括号 |
| 下标 | `x_i`、`x_(i,j)` | 复杂下标加括号 |
| 分数 | `a/b`、`(a+b)/(c+d)` | 分子分母记得加括号 |
| 根号 | `sqrt(2)`、`cbrt(8)` | 或 `根号2` |
| 矩阵 | `mat((1 2) (3 4))` | 行之间空格或逗号；外层括号即矩阵边界 |
| 向量/行列式 | `vec(v)`、`det(mat((a b) (c d)))` | |
| 求和 | `sum_(i=1)^n a_i` | 下限 `_`、上限 `^` |
| 积分 | `int_a^b f(x) dx` | |
| 极限 | `lim_(x->0) sin(x)/x` | `->` 表示趋向 |
| 同余 | `a ≡ b (mod m)` 或 `a = b mod m` | 中文"模 m 同余"也行 |
| 组合数 | `C(n, k)` 或 `binom(n, k)` | |
| 共轭/均值 | `x-bar`、`x-hat`、`x-tilde` | 也可写 `conj(z)` |
| 转置 | `A^T`、`A'` | |
| 点乘 | `a · b` 或 `a dot b` | |
| 无穷 | `inf`、`+inf` | |
| 绝对值/范数 | `|x|`、`||v||` | |
| 集合 | `{x in R : x^2 < 2}` | 或 `集合 {x∈R | x²<2}` |
| 量词 | `forall x`、`exists x` | |
| 属于/包含 | `x in A`、`A subset B` | |
| 整除 | `a | b`（读作 a 整除 b） | 与绝对值共用竖线，靠语境区分 |
| 渐近 | `f ~ g`、`O(n^2)` | |
| 上确界/下确界 | `sup S`、`inf S` | |
| 最大值/最小值 | `max(a,b)`、`min(a,b)` | |

**示例对话**：

> 用户：求 mat((1 2) (3 4)) 的行列式。
> AI 理解：$\det\begin{pmatrix}1&2\\3&4\end{pmatrix}=1\cdot4-2\cdot3=-2$。

> 用户：证明 sum_(k=1)^n k^2 = n(n+1)(2n+1)/6。
> AI 理解：$\sum_{k=1}^n k^2=\frac{n(n+1)(2n+1)}{6}$。

### 简化写法的原则

1. **写清边界**：`a+b/c` 有歧义（是 $a+\frac bc$ 还是 $\frac{a+b}{c}$？），写成 `(a+b)/c`；
2. **上下标加括号**：`x^(n+1)`、`a_(i,j)`；
3. **中文说明兜底**：实在不会写，用中文描述"3 行 3 列矩阵，第 i 行第 j 列是 1/(i+j)"——AI 一样能理解；
4. **告诉 AI 你的记号**：如果你用了特殊记号（如 `f*` 表示共轭），先说一句"记号说明"。

## 拍照方案（多模态可用时）

如果用的是支持图片的多模态模型，**手写公式拍照**是最省事的方案：

- 纸面书写工整，一行一个公式；
- 复杂结构（矩阵、分段函数、积分）拍照比打字快得多；
- 拍照后口头补充符号说明（如"第二个矩阵是 2 行 3 列"）；
- AI 会转写为 LaTeX 并与你确认——发现转写错误时直接口头指正。

如果用的是**纯文本模型**：优先用上面的简化记号；写不出的复杂对象（大矩阵、长推导）可分段描述，或拆成多个小问题逐个问。

2. 用简化记号表达 $\sum_{i=1}^{n}\sum_{j=1}^{m} a_{ij}$；
3. 向 AI 描述一个 2×2 矩阵的乘法规则，只用中文，看它能否正确转写为公式。
