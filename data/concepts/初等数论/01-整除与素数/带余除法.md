# 带余除法

## 引入问题

$17$ 支笔平均分给 $5$ 个人，每人得几支？还剩几支？答案是每人 $3$ 支，余 $2$ 支——即 $17 = 5 \times 3 + 2$。这个"分物有剩余"的日常经验就是带余除法的直观来源。

更形式化的问题：对任意整数 $a$（正、负或零）和非零整数 $b$，是否总能找到商 $q$ 和余数 $r$？而且它们是否唯一确定？

## 正式定义

> **带余除法定理**：
> 对任意整数 $a$ 和非零整数 $b$，存在**唯一**的整数对 $(q,r)$ 使
>
> $$
> a = bq + r,\qquad 0 \le r < |b|.
> $$
>
> 其中 $q$ 称为**商**，$r$ 称为**余数**。

定理包含两个独立断言：
- **存在性**：这样的 $(q,r)$ 一定找得到；
- **唯一性**：找到后不会有第二组满足同样条件的 $(q,r)$。

## 直观解释

想象在数轴上以 $b$ 为单位刻出等距的网格点 $\{\ldots, -2b, -b, 0, b, 2b, \ldots\}$。整数 $a$ 必定落在某两个相邻网格点之间（或恰好在某个点上）。余数 $r$ 就是 $a$ 距离左边那个网格点的偏移量，商 $q$ 标记了 $a$ 在第几段区间里。

## 基本例子

| $a$ | $b$ | 等式 | 商 $q$ | 余数 $r$ |
|-----|-----|------|--------|---------|
| $17$ | $5$ | $17 = 5\cdot 3 + 2$ | $3$ | $2$ |
| $-17$ | $5$ | $-17 = 5\cdot(-4) + 3$ | $-4$ | $3$ |
| $17$ | $-5$ | $17 = (-5)\cdot(-3) + 2$ | $-3$ | $2$ |
| $0$ | $7$ | $0 = 7\cdot 0 + 0$ | $0$ | $0$ |

第二行尤其值得注意：$-17$ 除以 $5$ 的标准余数是 $\boxed{3}$，不是 $-2$。因为定理要求 $r \ge 0$。

## 为什么非负余数约定很重要？

不同编程语言的求余运算可能返回负余数（如 Python 中 `-17 % 5 = 3`，但 C 语言中 `-17 % 5 = -2`）。数学中的带余除法统一要求 $0 \le r < |b|$，这样：
- 每个整数恰好落在一个同余类里，不会有歧义；
- 后续的同余理论、欧几里得算法都依赖这一约定。

## 存在性证明概要

用**良序原理**。考虑集合

$$
S = \{ a - bk : k \in \mathbb{Z},\ a - bk \ge 0 \}.
$$

若 $b > 0$，取足够负的 $k$ 使 $bk$ 很小，所以 $S$ 非空。由良序原理，$S$ 有最小元，记为 $r = a - bq$。若有 $r \ge b$，则 $r - b = a - b(q+1)$ 也在 $S$ 中且更小，矛盾。故 $0 \le r < b$。

若 $b < 0$，用 $|b|$ 代替 $b$ 论证相同（因为 $a = bq + r = (-b)(-q) + r$）。

## 唯一性证明概要

设 $(q,r)$ 和 $(q',r')$ 都满足条件。则

$$
bq + r = a = bq' + r'\ \implies\ b(q-q') = r' - r.
$$

左边是 $b$ 的倍数（或为零），右边满足 $|r' - r| < |b|$（因为 $0 \le r,r' < |b|$）。唯一可能是两边同时为 $0$，即 $q=q'$、$r=r'$。

## 边界情况

- **$a = 0$**：对任何 $b\ne 0$，有 $0 = b\cdot 0 + 0$，商和余数都是 $0$。
- **$a$ 能被 $b$ 整除**：此时余数 $r = 0$。带余除法退化为整除。
- **$|a| < |b|$**：商 $q = 0$，余数 $r = a$（若 $a \ge 0$）或需要调整（若 $a < 0$）。例如 $3 = 7\cdot 0 + 3$，但 $-3 = 7\cdot(-1) + 4$。

## 常见错误

| 错误 | 正确做法 |
|------|----------|
| 认为 $-17 \div 5$ 的余数是 $-2$ | 数学约定要求非负余数，答案是 $3$：$-17 = 5\cdot(-4)+3$ |
| 把商和余数当成有理数除法中的概念 | 商必须是整数，余数必须满足 $0 \le r < |b|$ |
