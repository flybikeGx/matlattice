# 一元二次方程

## 引入问题

一个矩形面积 $24\text{ m}^2$，周长 $20\text{ m}$。长和宽各是多少？

设长为 $x$，则宽为 $\frac{20-2x}{2}=10-x$。由面积关系：$x(10-x)=24$，即 $x^2-10x+24=0$。这是一元二次方程。

## 标准形式

只含一个未知数、最高次数为 $2$ 的方程可写成：

$$ax^2 + bx + c = 0 \quad (a \neq 0)$$

其中 $a, b, c$ 是常数，分别称为二次项系数、一次项系数和常数项。

## 求根公式（配方法推导）

**定理**：方程 $ax^2+bx+c=0$ 的解为

$$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$$

**推导**：

第一步：两边除以 $a$。

$$x^2 + \frac{b}{a}x + \frac{c}{a} = 0$$

第二步：移项。

$$x^2 + \frac{b}{a}x = -\frac{c}{a}$$

第三步：配方——两边加 $\left(\frac{b}{2a}\right)^2$。

$$x^2 + \frac{b}{a}x + \left(\frac{b}{2a}\right)^2 = -\frac{c}{a} + \left(\frac{b}{2a}\right)^2$$

第四步：左边化为完全平方，右边通分整理。

$$\left(x + \frac{b}{2a}\right)^2 = \frac{b^2-4ac}{4a^2}$$

第五步：两边开方。

$$x + \frac{b}{2a} = \pm \frac{\sqrt{b^2-4ac}}{2a}$$

第六步：移项即得求根公式。

$$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$$

> **直观理解**：配方的核心思想是把 $ax^2+bx$ 补成一个完全平方。加的那个数 $\left(\frac{b}{2a}\right)^2$ 恰好是"一次项系数的一半的平方"。

## 判别式

$\Delta = b^2 - 4ac$ 决定了实数根的情况：

| 判别式 | 根的情况 |
|--------|---------|
| $\Delta > 0$ | 两个不相等的实数根 |
| $\Delta = 0$ | 一个重根（两相等实根） $x = -\dfrac{b}{2a}$ |
| $\Delta < 0$ | 无实数根（在复数域内有一对共轭复根） |

## 数值例子

**例1**（$\Delta > 0$）：$x^2 - 5x + 6 = 0$

$\Delta = 25-24=1>0$，得 $x_1=2, x_2=3$。也可以直接因式分解 $(x-2)(x-3)=0$。

**例2**（$\Delta = 0$）：$4x^2 - 4x + 1 = 0$

$\Delta = 16-16=0$，得 $x = \dfrac{4}{8} = \dfrac{1}{2}$。即 $(2x-1)^2=0$。

**例3**（$\Delta < 0$）：$x^2 + x + 1 = 0$

$\Delta = 1-4=-3<0$，无实数根。

## 韦达定理

两根之和与两根之积可以直接由系数读出（$x_1+x_2=-b/a$、$x_1x_2=c/a$）。这是求解与构造二次方程的重要工具，详见独立节点：

<div require="elementary.algebra.vieta-theorem">
**韦达定理**：若 $x_1,x_2$ 是 $ax^2+bx+c=0$ 的两根，则 $x_1+x_2=-\frac{b}{a}$、$x_1x_2=\frac{c}{a}$。不解方程就能获知根的和与积，对构造方程、检验结果和判断根的符号都很有用。
</div>

## 解法选择策略

1. **能因式分解** → 优先用因式分解（快）
2. **不能快速分解** → 用求根公式（通用但计算量大）
3. 先算判别式判断根的存在性和个数

## 常见错误

- 代入求根公式时符号搞混（$b$ 前面已有负号，不要把 $+3x$ 的 $b$ 写成 $3$，应该写 $b=3$；而 $-3x$ 应写 $b=-3$）
- 忽略判别式的意义，得出"方程一定有两个实根"的错误直觉

## 检查理解

1. 不解方程，判断 $3x^2 + x - 4 = 0$ 有几个实根。两根之和与积各是多少？
2. 已知一个一元二次方程的两根之和为 $5$，两根之积为 $6$。你能写出这个方程吗？
