# 数与式

## 引入问题

小明买了 $3$ 支铅笔和 $2$ 块橡皮，共花了 $16$ 元。如果只告诉你说"铅笔的单价是橡皮的 $2$ 倍"，你能算出各自的价格吗？

要回答这类问题，需要先把文字描述翻译成**数学表达式**。

## 数集

代数中常用的数集从小到大依次包含：

- **自然数** $\mathbb{N} = \{0, 1, 2, 3, \dots\}$（有时不含 $0$）
- **整数** $\mathbb{Z} = \{\dots, -2, -1, 0, 1, 2, \dots\}$
- **有理数** $\mathbb{Q}$：能写成 $\frac{p}{q}$（$p,q$ 为整数，$q\neq 0$）的数。例如 $\frac{3}{4}, -2.5 = -\frac{5}{2}$。
- **实数** $\mathbb{R}$：包含有理数和无理数（如 $\sqrt{2}, \pi, e$）。

关系：$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$。

> **直观理解**：有理数是"能精确写成分数的数"，无理数是"不能写成分数的数"——它们的小数部分既不尽也不循环。

## 变量与表达式

- **变量**是用字母（如 $x, y, a, b$）代表未知数或可变数量的符号。
- **代数式**是由数、变量和运算符号组合而成的数学表达式，如 $3x^2 - 5x + 1$。

一个表达式代表一个**计算规则**。例如 $3x+2$ 的含义是：先乘以 $3$，再加 $2$。当 $x=4$ 时，值为 $3(4)+2 = 14$。

## 运算律

所有实数运算满足以下基本法则：

| 运算律 | 公式 |
|--------|------|
| 交换律（加法） | $a + b = b + a$ |
| 交换律（乘法） | $ab = ba$ |
| 结合律（加法） | $(a+b)+c = a+(b+c)$ |
| 结合律（乘法） | $(ab)c = a(bc)$ |
| 分配律 | $a(b+c) = ab + ac$ |

**分配律是最常用的工具**——展开与合并同类项都依赖它。

## 化简与代入

**化简**就是把表达式写成最简形式：

> 例：化简 $2(3x-4) + 5(x+1)$
> 
> $$= 6x - 8 + 5x + 5 = 11x - 3$$

关键步骤：① 用分配律展开括号 ② 合并同类项。

**代入**就是把变量的具体值带入表达式求值：

> 例：当 $x = -2$ 时，$x^2 - 3x + 1 = (-2)^2 - 3(-2) + 1 = 4 + 6 + 1 = 11$。
> 
> **常见错误**：忘记括号——代入负数时要加括号避免符号错误，如 $(-2)^2 \neq -2^2$（前者等于 $4$，后者等于 $-4$）。
