# 一元一次方程

## 引入问题

某手机套餐每月固定费用 $30$ 元，通话每分钟 $0.2$ 元。这个月你话费账单显示 $58$ 元——你打了多少分钟？

把"通话分钟数"设为 $x$，得到方程：$30 + 0.2x = 58$。解出 $x$ 就是答案。

## 直观解释

一元一次方程描述了一个**线性关系**。求解就是找到使等式成立的那个唯一输入值。

## 定义与标准形式

只含有一个未知数，且未知数的最高次数为 $1$ 的方程称为**一元一次方程**，可写成：

$$ax + b = 0 \quad (a \neq 0)$$

其中 $a$ 是未知数的系数，$b$ 是常数项。

## 等式的性质

解方程的依据是以下两条基本性质——对等式两边做相同的可逆操作，**不改变解集**：

1. **同加（减）**：若 $A = B$，则 $A + c = B + c$
2. **同乘（除）非零数**：若 $A = B$，且 $c \neq 0$，则 $Ac = Bc$

> **为什么除以零不行？** 因为任何数乘以零都等于零，这个操作不可逆——你无法从 "$0 = 0$" 推断回原方程。

## 解方程步骤

以 $5(2x - 3) - 7 = 3(x + 1)$ 为例：

| 步骤 | 说明 |
|------|------|
| 展开：$10x - 15 - 7 = 3x + 3$ | 用分配律去掉括号 |
| 合并常数：$10x - 22 = 3x + 3$ | 整理同类项 |
| 移项：$10x - 3x = 3 + 22$ | 未知数到左边，常数到右边（实质是同加 $-3x+22$） |
| 合并：$7x = 25$ | |
| 除以系数：$x = \frac{25}{7}$ | |

**验证**：代入检验 $5(2\cdot\frac{25}{7}-3)-7 = \frac{250}{7}-15-7 = \frac{250-168}{7} = \frac{82}{7}$，右边 $3(\frac{25}{7}+1) = \frac{108}{7}$——算一下确认两边相等。

## 含参数的讨论

当系数本身含字母时，需要分类讨论：

> 例：解 $(m-1)x = 3$
> 
> - 若 $m \neq 1$（即系数不为零），则 $x = \dfrac{3}{m-1}$
> - 若 $m = 1$，左边为 $0$，右边为 $3$——**无解**

## 应用题建模思路

1. **设未知数**：用变量表示问题中要求的量
2. **找等量关系**：从文字中提取"等于""共""是...的几倍"等关键词
3. **列方程并求解**
4. **检验合理性**：解是否满足实际约束（如人数必须为正整数）

## 常见错误

- 移项时忘记变号（如 $5x - 3 = 2x + 7$ → 应为 $3x = 10$，不能写成 $3x = 4$）
- 两边同时除以一个可能为零的表达式前不讨论是否为零

## 检查理解

1. 解方程 $4(3x+1) - 2(x-5) = 6x + 20$，得到什么结果？
2. 某商店进价 $p$ 元/件，零售价比进价高 $30\%$。若一件商品售价 $78$ 元，求 $p$。
