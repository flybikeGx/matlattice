# 对数运算

## 引入问题

投资按年利率 $5\%$ 复利增长，本金翻倍需要多少年？即解 $1.05^x = 2$。

这个方程的未知数在**指数位置**上——常规代数手段难以直接求解。这正是对数的用武之地：$x = \log_{1.05} 2 \approx 14.2$ 年。

## 直观解释

如果加法是重复的"加 $1$"，乘法是重复的"加法"，那么指数运算是重复的"乘法"。**对数就是它的逆运算**——回答"多少次乘方才能达到目标值"。

| 运算 | 已知两个数求第三个 |
|------|-------------------|
| 减法 = 加法逆运算 | $x + a = b \implies x = b - a$ |
| 除法 = 乘法逆运算 | $xa = b \implies x = b/a$ |
| **对数 = 指数逆运算** | $a^x = b \implies x = \log_a b$ |

## 定义

若 $a^y = x$（$a > 0$，$a \neq 1$，$x > 0$），则称 $y$ 为以 $a$ 为底 $x$ 的对数：

$$y = \log_a x \iff a^y = x$$

其中 $a$ 是底数，$x$ 是真数。

> **注意定义域**：真数必须为正（$x > 0$），底数为正且不等于 $1$。

## 常用对数与自然对数

- **常用对数**：以 $10$ 为底，记作 $\log x$ 或 $\lg x$
- **自然对数**：以 $e \approx 2.718$ 为底，记作 $\ln x$

自然对数在物理、经济、高等数学中无处不在——因为 $e^x$ 是唯一导数等于自身的函数。

## 基本性质

| 性质 | 公式 |
|------|------|
| 单位元的对数 | $\log_a 1 = 0$（因为 $a^0 = 1$） |
| 底数的对数 | $\log_a a = 1$（因为 $a^1 = a$） |
| 积的对数 | $\log_a(xy) = \log_a x + \log_a y$ |
| 商的对数 | $\log_a\left(\dfrac{x}{y}\right) = \log_a x - \log_a y$ |
| 幂的对数 | $\log_a(x^k) = k \log_a x$ |

**证明示例**：为什么 $\log_a(xy) = \log_a x + \log_a y$？

设 $\log_a x = p$，$\log_a y = q$，则 $x = a^p$，$y = a^q$。于是 $xy = a^p \cdot a^q = a^{p+q}$，所以 $\log_a(xy) = p + q = \log_a x + \log_a y$。

## 换底公式

**定理**：$\log_b x = \dfrac{\log_a x}{\log_a b}$（其中 $a, b > 0$ 且 $a, b \neq 1$，$x > 0$）。

**证明**：设 $\log_b x = y$，则 $b^y = x$。两边取以 $a$ 为底的对数：$\log_a(b^y) = \log_a x$。由幂的对数性质得 $y \log_a b = \log_a x$，所以

$$y = \dfrac{\log_a x}{\log_a b} \implies \log_b x = \dfrac{\log_a x}{\log_a b}$$

> **用途**：计算器通常只支持 $\log$（底 $10$）和 $\ln$（底 $e$），换底公式让我们能计算任意底的对数。
> 
> 例：$\log_2 8 = \dfrac{\ln 8}{\ln 2} = \dfrac{3\ln 2}{\ln 2} = 3$

## 对数方程与指数方程的互化

解对数方程的关键是把对数式转为指数式：

> **例**：解 $\log_3(x+1) = 4$
> 
> 转指数：$x+1 = 3^4 = 81$，所以 $x = 80$。
> 
> **验证**：$\log_3(81) = \log_3(3^4) = 4$ ✓

解指数方程的关键是对等式两边取对数：

> **例**：解 $5^{2x-1} = 125$
> 
> 两边取以 $5$ 为底的对数：$2x-1 = \log_5(125) = 3$，所以 $x = 2$。

## 常见错误

- 把 $\log(x+y)$ 拆成 $\log x + \log y$——这是错误的！积的对数才等于对数的和
- 忽略真数必须为正的条件，导致解出负根后未舍去
- 混淆 $\log_a x^2 = 2\log_a |x|$（注意绝对值，因为 $x^2 > 0$ 即使 $x < 0$）

## 检查理解

1. 用换底公式计算 $\log_3 7$ 的近似值（可用 $\log$ 或 $\ln$）。
2. 解方程 $\ln(x+2) - \ln x = 1$。提示：先用对数的商的性质合并，再转指数式。注意验证真数为正。
3. 化简 $\log_2 16 + \log_2\left(\dfrac{1}{4}\right) - \log_2(\sqrt{8})$。
