# 勾股定理

## 引入问题

古埃及的建筑师把绳子打成 12 个等距的结，然后拉成 $3:4:5$ 比例的三角形来确保直角。为什么恰好是这三个数字？它们背后隐藏着什么规律？

**直观理解**：在直角三角形中，两条较短边的平方和恰好等于最长边（斜边）的平方。这不是偶然——这是空间本身的结构决定的。

---

## 正式陈述

> **定理**（勾股定理）：在直角三角形中，若两直角边分别为 $a$ 和 $b$，斜边为 $c$，则：
$$a^2 + b^2 = c^2$$

其中"直角边"是夹直角的两条边，"斜边"是直角的对边。

---

## 直观理解：面积拼图

考虑以下经典说明（赵爽弦图法）：

以直角三角形的三边为边长分别作三个正方形。可以证明：两个较小正方形的面积之和恰好等于大正方形的面积。

**思路简述**：将一个大正方形内部分割重排，左侧布局给出 $c^2$ 的面积表达式，右侧重新排列后给出 $a^2 + b^2$ 的布局——两种布局占据同一块区域，所以相等。

> 勾股定理有超过 200 种已知证明方法，包括面积拼图法、相似三角形法和代数法。详细证明可参考专门的 proof 节点。

---

## 数值例子：勾股数组

> **勾股数组**（Pythagorean triple）是指三个正整数 $(a, b, c)$ 满足 $a^2 + b^2 = c^2$。

常见的本原勾股数组（三数互质）：

| 数组 | 验证 |
|------|------|
| $(3, 4, 5)$ | $9 + 16 = 25 \checkmark$ |
| $(5, 12, 13)$ | $25 + 144 = 169 \checkmark$ |
| $(8, 15, 17)$ | $64 + 225 = 289 \checkmark$ |
| $(7, 24, 25)$ | $49 + 576 = 625 \checkmark$ |

任意勾股数组的正整数倍也是勾股数组。例如 $(3, 4, 5)$ 的 2 倍是 $(6, 8, 10)$，验证：$36 + 64 = 100 \checkmark$。

---

## 逆定理

> **定理**（勾股定理的逆）：在 $\triangle ABC$ 中，若 $a^2 + b^2 = c^2$（其中 $c$ 是最长边），则该三角形为直角三角形，且 $\angle C = 90^\circ$。

### 应用

已知三边为 $7, 24, 25$。检验：$7^2 + 24^2 = 49 + 576 = 625 = 25^2$。由逆定理知这是直角三角形，且 $25$ 是斜边所对的角为直角。

若三边为 $(5, 6, 8)$：$25 + 36 = 61 \neq 64$。这不是直角三角形（实际上 $61 < 64$ 说明最长边对应的角为钝角）。

---

## 应用实例：两点间距离

在平面上，点 $A(x_1, y_1)$ 与点 $B(x_2, y_2)$ 之间的距离可以用勾股定理推导（详见"直角坐标系"）：
$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

**例子**：$A(1, 3)$ 与 $B(4, 7)$ 的距离为 $\sqrt{(4-1)^2 + (7-3)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$。这正是 $(3, 4, 5)$ 勾股组的实际应用。

---

## 常见错误

- **斜边不是最长的边**：斜边必须是直角所对的边，也就是三边中最长的一条。不要把短边的平方和与任意第三边的平方做比较。
- **忘记开方**：由 $a^2 + b^2 = c^2$ 求 $c$ 时，别忘了 $c = \sqrt{a^2 + b^2}$，不是直接加。
- **逆定理用错方向**：逆定理要求验证的是**最长边**的平方是否等于另两边的平方和，不是任意顺序。

2. 已知三边长为 $10, 17, 21$。这是直角三角形吗？请用勾股定理验证并说明理由。
3. 若 $a^2 + b^2 < c^2$（$c$ 是最长边），这个三角形的最大角是锐角、直角还是钝角？说说你的直觉判断。
