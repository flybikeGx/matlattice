# 基本图形与角

## 引入问题

在纸上画一个三角形——这个简单的图形由哪些更基本的元素构成？三条线段、三个交点。要理解几何，我们必须先搞清楚这些基本构件是什么。

**直观理解**：几何就像搭积木，点是最小的单位，由点组成线，由线围成面。角则是两条线的"张开程度"。

---

## 点、线、射线

### 点
- **点**是位置的基本标记，没有长度、宽度和厚度。用大写字母命名：$A, B, C$。
- **公理**：两点确定唯一一条直线。

### 直线与线段
- **直线**向两端无限延伸，没有端点。记作直线 $AB$ 或直线 $l$。
- **线段**是直线上两点之间的部分，有确定的长度，记作 $\overline{AB}$。

### 射线
- **射线**从端点出发，沿一个方向无限延伸。记作射线 $\overrightarrow{OA}$（$O$ 为端点）。

---

## 角的概念

### 定义

由同一端点引出的两条射线构成的图形叫做**角**。公共端点叫**顶点**，两条射线叫**边**。角通常用三个字母表示，如 $\angle AOB$（$O$ 为顶点），也可以用数字或希腊字母标记：$\angle \alpha, \angle 1$。

### 角的度量

平面几何中常用**度（$^\circ$）**作单位：周角为 $360^\circ$。其他单位还有弧度，后续会学习。

---

## 角度分类

按度数大小，角分为以下类型：

| 名称 | 范围 | 图示特征 |
|------|------|----------|
| 锐角 | $0^\circ < \alpha < 90^\circ$ | 张开幅度小于直角 |
| 直角 | $\alpha = 90^\circ$ | 两边垂直，标记为小方块 |
| 钝角 | $90^\circ < \alpha < 180^\circ$ | 张开幅度大于直角但小于平角 |
| 平角 | $\alpha = 180^\circ$ | 两射线成一条直线 |
| 周角 | $\alpha = 360^\circ$ | 两射线重合，转过一圈 |

---

## 互补角与互余角

- **互余角**：两个角的度数之和为 $90^\circ$。即若 $\angle A + \angle B = 90^\circ$，称 $\angle A$ 与 $\angle B$ 互余。
- **互补角**：两个角的度数之和为 $180^\circ$。即若 $\angle A + \angle B = 180^\circ$，称 $\angle A$ 与 $\angle B$ 互补。

**记忆口诀**："余"是余下补到直角（$90^\circ$），"补"是补成平角（$180^\circ$）。

### 例子

$\angle A = 35^\circ$，则它的余角为 $90^\circ - 35^\circ = 55^\circ$，补角为 $180^\circ - 35^\circ = 145^\circ$。

---

## 对顶角相等

两条直线相交于点 $O$，形成的相对的两个角称为**对顶角**。

**定理**：对顶角相等。即若直线 $AB$ 与 $CD$ 交于 $O$，则 $\angle AOC = \angle BOD$，$\angle AOD = \angle BOC$。

### 简要证明思路

因为 $\angle AOC$ 与 $\angle AOD$ 互补（构成平角），$\angle BOD$ 与 $\angle AOD$ 也互补。同一个角的补角相等，所以 $\angle AOC = \angle BOD$。

---

## 常见错误

- **互余和互补混淆**：和为 $90^\circ$ 是互余（"余"到直角），和为 $180^\circ$ 是互补（补成平角）。
- **对顶角的前提**：必须来自两条直线相交，不是任意两个"相对的角"都相等。
