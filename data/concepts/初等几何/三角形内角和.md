# 三角形内角和

## 引入问题

无论三角形是什么形状——尖瘦的、扁平的、几乎等边的——三个内角加起来总是 $180^\circ$。为什么？这个结论如此普适，一定有深层的原因。

**直观理解**：想象把三角形的三个角"剪下来"拼在一起，它们恰好排成一条直线——一个平角。这不是巧合，而是平行线性质的必然结果。

---

## 定理与证明

> **定理**（三角形内角和）：在欧氏平面中，任意三角形三个内角之和等于 $180^\circ$。

### 标准证明概要

设 $\triangle ABC$。过顶点 $C$ 作直线 $DE \parallel AB$。

1. 因为 $DE \parallel AB$，$\angle BAC = \angle ACD$（内错角相等）。
2. 同理，$\angle ABC = \angle BCE$（内错角相等）。
3. $\angle ACD + \angle ACB + \angle BCE$ 恰好构成平角 $\angle DCE$，即 $180^\circ$。
4. 代入得：$\angle BAC + \angle ABC + \angle ACB = 180^\circ$。

$$\text{在 }\triangle ABC\text{ 中：}\angle A + \angle B + \angle C = 180^\circ$$

---

## 推论

### 直角三角形两锐角互余

若 $\angle C = 90^\circ$，则 $\angle A + \angle B = 180^\circ - 90^\circ = 90^\circ$。

**例子**：在直角 $\triangle ABC$ 中，$\angle A = 34^\circ$，则 $\angle B = 90^\circ - 34^\circ = 56^\circ$。

### 等腰三角形底角相等

若 $AC = BC$，则由"等边对等角"知 $\angle A = \angle B$。结合内角和定理：
$$2\angle A + \angle C = 180^\circ \implies \angle A = \frac{180^\circ - \angle C}{2}$$

**例子**：等腰三角形顶角为 $40^\circ$，则每个底角为 $(180^\circ - 40^\circ) / 2 = 70^\circ$。

---

## 外角定理

> **定理**（外角定理）：三角形的一个外角等于不相邻的两个内角之和。

即 $\triangle ABC$ 中，延长 $BC$ 到 $D$，则：
$$\angle ACD = \angle BAC + \angle ABC$$

### 简要证明

$\angle ACD$ 与 $\angle ACB$ 互补（构成平角），所以：
$$\angle ACD + \angle ACB = 180^\circ$$
同时三角形内角和为 $180^\circ$，所以：
$$\angle BAC + \angle ABC + \angle ACB = 180^\circ$$

两式相减即得 $\angle ACD = \angle BAC + \angle ABC$。

---

## 常见错误

- **外角等于相邻内角**：外角等于的是**不相邻**的两个内角之和，不是和它挨着的那个内角。
- **把内角和定理套用到非欧几何**：在球面上三角形内角和大于 $180^\circ$，在双曲平面上小于 $180^\circ$。此定理依赖平行公理，是欧氏几何专属性质。

---

## 检查理解

1. 已知 $\triangle ABC$ 中，$\angle A : \angle B : \angle C = 2:3:4$。求每个角的度数。
2. 利用外角定理证明：三角形任一外角大于任意一个不相邻的内角。你的论证思路是什么？
3. 一个三角形的两个内角分别为 $72^\circ$ 和 $65^\circ$，第三个角是锐角、直角还是钝角？
