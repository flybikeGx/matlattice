# 项目愿景

最终产品以 skills 交付。使用时，AI 先读取一份课程大纲和用户存档，再作为教师向人类学生授课。

课程不是一段固定讲义，而是相互配合的结构：

1. 传统课程文件夹分别组织概念、证明和练习；
2. JSON 路径负责选择顺序与回访；
3. 用户存档和 require 规则决定此刻能展示什么。

项目首先验证：

- AI 能否从课程大纲中选出正确的下一节点；
- 同一个旧节点能否在新知识完成后显示新的段落；
- 学习进度能否由脚本可靠维护，而不是由模型随手改文件；
- skill 能否把大纲转化为有提问、尝试、提示和评估的真实教学过程。

当前先用完整的初等数论基础网验证结构，不构建复杂前端。
